# Navigation

Always-dark Portal chrome. Sidebar depends on role. On phones and tablets under 1024px, the sidebar is hidden behind a menu button in the header.

Sidebar category headings use compact spacing, with 0.675rem above each heading.

## Everyone signed in

- Announcements
- Dashboard (students) or Packages (producers)
- Master Calendar
- PA (under Announcements; assigned announcers and producers can edit)
- Package Cycles (dates)
- InFocus Drive (opens `drive.infocuspaly.com`)
- Teleprompter (opens `teleprompter.infocuspaly.com`)
- Livestream Tracker
- Extension Requests
- Settings

## Students (and APs who are on a package)

**The Cycle:** Information, Brainstorming, A-roll/B-roll, Initial Cut, Final Cut.

Later tabs are visible but disabled until the previous stage unlocks. Grades (`/grades`) shows for reporters and APs, not for EP/adviser/super admin.

## Producers (associate and up)

- Groups
- Members
- Package Cycle (roster)
- Publishing Queue
- The Show
- Participation (associate and up; Grade Editor is executive and up)
- Submitted announcements
- Admin Dashboard (executive and up)
- Passwords (key icon next to sign out at the bottom of the sidebar; see `passwords.md`)

## Portal assistant

Everyone signed in gets a green ✱ in the bottom-right of Portal. It opens a floating popup with **Assistant** (chatbot) and **Messages** (group and direct chat). Unread messages show on the ✱. Ask “where is Groups?” (or another tab or package) and a **Take me there** card can open that page. Reporters cannot look up grades or producer-only surfaces. Associates cannot look up grades. Bare video review hides it so it does not cover the player.

## Other routes

| Route | Who |
|---|---|
| `/information` | Cycle rules for students |
| `/projects/.../review` | Media review (producers / project members) |
| `/grade-editor` | Executives, adviser, super admin |
| `/class-board` | Everyone signed in. Not in the sidebar. Classroom display of the current cycle, livestreams, and calendar |
| `/master-calendar` Anchors & PA button | Executives, adviser, super admin |
| `/equipment` | Equipment checkout (also `equipment.infocuspaly.com`) |
| `/submit-announcement` | Public form, no Portal login |
| `/g/[token]` | Guest review link |
