# Settings, notifications, onboarding

## Onboarding (`/onboarding`)

First sign-in: set a nickname (the name Portal shows) and notification channels.

## Settings (`/settings`)

- Playback: autoplay, sound, grid/list.
- Class Board PIN for super admins and the adviser. It opens `/class-board` only.
- Email and browser push for announcements, comments, and grades.
- Test email.
- Mac app notification permission (desktop wrapper).

Package stage events also email and push the people who need to act (students vs assigned producer vs adviser vs EPs).
