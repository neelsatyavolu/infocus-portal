# InFocus Portal knowledge

Product knowledge for people who use InFocus Portal and for a future in-app chatbot. Write for operators and students, not for engineers.

Class rules the app must enforce: `docs/class-rules-2026-27.md`. NAS/Drive paths: `docs/NAS-STORAGE.md`. Hosts: `docs/SUBDOMAINS.md`.

## Chatbot corpus

Index these files. Do not train on `AGENTS.md`, `GEMINI.md`, or `docs/superpowers/` (those are agent/engineering notes). Prefer this folder over the marketing `README.md` at the repo root.

When answering:

1. Match the user's role (student, associate producer, executive producer, adviser, super admin).
2. Cite the route (`/groups`, `/admin`) and the file below.
3. If this folder and the live UI disagree, the UI plus `docs/class-rules-2026-27.md` win — then update this folder.

## Agents must update this

When you change a Portal surface, access rule, email, or user-facing flow, update the matching file **in the same change**. If you add a page or host, add a row here and a new file. Do not leave chatbot docs stale.
