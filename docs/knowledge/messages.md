# Messages

The green ✱ in the bottom-right opens a popup (full screen on phones). Switch from **Assistant** to **Messages** to chat with people in Portal. Hidden on bare video review. Unread counts show on the ✱ and on the **Messages** tab.

## Groups

Each package with a topic or roster has a group chat: the students on it plus the assigned associate and executive producer. Custom videos added only to the Publishing Queue are not group chats. One list mixes group chats and direct messages, newest activity first (a DM you just sent jumps to the top). Unread counts stay on the row. Group rows show the members’ names, with the package topic underneath. Search to start a new DM. Same visibility as Groups: reporters see packages they are on; associates see assigned packages (and any package they are on); executives, the adviser, and super admin see every package.

Anyone in that group can read and write.

Conversations show the latest 200 messages in chronological order. New messages remain visible when the conversation refreshes. Background refreshes keep your current conversation and keyboard focus; Back returns to the inbox even if a refresh is still pending.

Unread badges count only conversations you can currently access. Switching chats preserves each conversation’s unsent draft without carrying text into another chat. Enter sends a message, Shift+Enter adds a line break, and Enter used to confirm IME composition does not send. If opening a chat fails, the inbox shows the error.

## Direct

Producers (associate and up) can message a class member directly from **People**. That person can write back. Reporters cannot start a new direct chat; they see ones they are already in.

## Who it is for

Everyone signed in can open **Messages** and check chats they are allowed to see. This is not email or push — the badge on the ✱ is how you notice new messages.
